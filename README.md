# Ajay Kumar M

Personal site for [Ajay Kumar M](https://github.com/AjiMk) — lead engineer in Kochi. APIs, event-driven systems, and AI agents at Air India.

## Run

```bash
npm install
npm run dev
```

The site runs at http://localhost:8080.

```bash
npm run build
npm run typecheck
```

## Stack

TanStack Start, React, Tailwind CSS v4.

Copy lives in `src/lib/portfolio.ts`. Images are in `public/images/`.
