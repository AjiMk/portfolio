# Ajay Kumar M

Personal site for [Ajay Kumar M](https://github.com/AjiMk) — software engineer in Kochi building web applications, backend systems and integrations.

## Run

```bash
npm install
npm run dev
```

The site runs at http://localhost:8080.

```bash
npm run build
npm run typecheck
```

## Stack

TanStack Start, React, Tailwind CSS v4.

Copy lives in `src/lib/portfolio.ts`. Images are in `public/images/`.
